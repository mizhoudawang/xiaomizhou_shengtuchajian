# CharImageGen · 角色一致性生图（SillyTavern 插件）

给 SillyTavern 用的悬浮面板插件：**给角色建立固定的外观与服装档案，出图时自动锁住长相、随心换装**，
另外还带一个 94 人的二次元角色库、画师画风库，以及自定义角色导入。

> 作者：**小米粥大王**

---

## 它解决什么

| 问题 | 插件怎么对付 |
|---|---|
| 同一个人每次长得不一样 | **外观锁**：每个角色存一份固定身体特征 tag，出图时自动拼进提示词（所有生图入口都生效） |
| 衣服不受控、换装麻烦 | **服装库**：衣服独立成库、全局共享；「差分」= 同一套衣服的破损/半脱/换配件 |
| 构图全靠运气 | **镜头预设**：全身正面 / 背面 / 面部特写 / 三视图 一键选 |
| 想出原作角色却总不像 | **同人角色库**：94 个角色内置 booru 角色 tag，一键建档；也能**自己导入**（模板 + 接别的 AI） |
| 画风不像某个画师 | **画师画风**：把画师 tag 加进提示词（和 LoRA 互不冲突，可叠加） |
| 提示词中文不认 | **词库**：接你 SD-WebUI 的 danbooru 词库，中文→英文 tag |

## 安装（推荐：让酒馆自己装）

1. 酒馆 → **Extensions（扩展）面板** → **Install extension（安装扩展）**
2. 粘贴本仓库地址：

```
https://github.com/mizhoudawang/xiaomizhou_shengtuchajian
```

3. 点 Install，然后**刷新页面（F5）**。右下角会出现 🎨 悬浮球。

> 前提：**机器上装了 `git`**（酒馆的安装功能底层就是 `git clone`），仓库是**公开**的。

手动安装也行：把本仓库所有文件放进 `<酒馆>/data/default-user/extensions/CharImageGen/`，刷新即可。

### 装完还要做两件事

1. **把 `workflows/` 里的工作流复制到** `<酒馆>/data/default-user/user/workflows/`
   （这几个示例是给 **Anima / miaomiao** 系模型写的；换模型请用你自己的工作流，
   只要里面保留 `%prompt%` `%negative_prompt%` `%seed%` `%width%` `%height%` 这些占位符即可）
2. 酒馆 **Image Generation** → Source 选 `ComfyUI` → URL 填 `http://127.0.0.1:8188` → Workflow 选上面那份

**详细的零基础教程见 [`安装与使用说明.md`](安装与使用说明.md) 的「零、五分钟上手」** —— 从放文件到出第一张图，6 步。

## 依赖与搭配

### 必须有的

| 依赖 | 说明 |
|---|---|
| **SillyTavern** | 1.12 以上（用自带的 **Image Generation** 扩展，不需要装别的） |
| **ComfyUI** | 本地跑、能正常出图；酒馆 Image Generation 里 Source 选 `ComfyUI` |

### 可选搭配（不装也能用）

| 搭配 | 用来干嘛 | 不做会怎样 |
|---|---|---|
| **auto-illustrator** 之类的自动生图扩展 | 让酒馆在聊天时**自动**出图 | 只是不能自动出图；手动点面板或魔杖菜单一样出图，**外观锁照样生效** |
| **VideoHelperSuite**（ComfyUI 节点包） | 图生图：读你上传的参考图（`VHS_LoadImagePath`） | 只有「上传图片重绘」用不了（ComfyUI 自带的 `LoadImage` 只读它自己 `input/` 目录） |
| **SD-WebUI 的 danbooru 词库** | 中文 → 英文 tag 规范化、动作/表情候选词 | 中文提示词会**原样保留**（它不猜），不影响出图 |

### 本插件不依赖 auto-illustrator（很多人会问这个）

插件**不 import、不调用**任何第三方扩展，只 import 酒馆自己的核心模块
（`script.js` / `extensions.js` / `slash-commands/SlashCommandParser.js`），
并挂酒馆自带的生图钩子 **`SD_PROMPT_PROCESSING`**：

> 酒馆在把提示词交给 ComfyUI **之前**会广播这个事件，插件就在这一刻改写提示词。

所以**所有**生图入口都会吃到外观锁：

- 插件面板的「改写并生成 / 一键换装出图 / 绘图区」
- 魔杖菜单 🪄 里的一键生图
- `/imagine` 斜杠命令
- **auto-illustrator 这类扩展触发的自动出图**

一句话分工：**auto-illustrator 决定「什么时候出图」，本插件决定「出成什么样」** —— 是搭配关系，不是依赖关系。

装了 auto-illustrator 的用户还会额外受益于插件自带的一条正则：把世界书输出的
`image###提示词###` 转成它能识别的 `<!--img-prompt="…"-->` 注释（这样点聊天里的图片可以重新生成）。

## 主要功能速查

- **出图**：写场景 → 改写成生图语法 → 出图；带「出镜人物」「尺寸规格」
- **绘图区**：跟角色无关的独立画板，可文生图、可上传图片做图生图
- **同人角色**：94 个内置角色（原神 49 / 蔚蓝档案 15 / 明日方舟 14 / 崩铁 4 / 东方 4 / Fate 4 / 赛马娘 4）
  + 搜索 + 一键建档 + 设为出镜 + 每角色参考图
  + **自建角色**：手动填表（中文名 + 外观 tag + 标志性服装 + 别名/分级/备注）→ 保存即建档入库
  + **导入角色**：下载模板 / 贴 JSON / CSV / 段落文本 / 让别的 AI 按模板生成，也支持导出
- **自建服装**：自己填服装名与标签存进全局服装库；可指定「归到哪套衣服下当差分」，或强制新建分类
- **种子控制**：固定种子 / 🎲 随机 / 一键锁定「上次出图的种子」，方便复现同一张图
- **画师画风**：30 个画师，支持 `@名字` / `artist:名字` / 纯名字三种注入写法 + 权重
- **玩家主角**：你自己的外观与穿着，独立存档
- **一键换装出图**：选人 + 选衣 + 选镜头 → 直接出图
- **词库**：搜词、抽动作、改写时喂候选词、出图前中文→英文规范化
- **设置**：工作流、denoise、LoRA 开关、界面主题（6 套配色）、尺寸、裸体兜底等

## 界面

- 右下角 🎨 可**拖动**到任意位置，点一下开/关面板；面板可拖、可双击折叠、**右下角拖拽改大小**
- 6 套主题：跟随酒馆 / 纯黑 / 深灰 / 浅灰 / 纯白 / 米色（护眼）

## 数据与隐私

- 插件**不收集、不上传**任何数据；所有解析、检索、中文转换都在浏览器本地完成
- 你的角色档案、服装库、API 设置**不在本插件文件夹里**，而是存在酒馆的 `settings.json`，
  所以分享/更新插件不会带出你的个人数据
- 本仓库**不包含**任何词库数据文件（那些来自你自己的 SD-WebUI）
